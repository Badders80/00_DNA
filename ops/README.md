# Ops Folder: Operational Reference

**Purpose:** Tracks "why" decisions are made and evaluates new tools. This is the ecosystem's operational memory for long-term alignment.

**Key Rules:**
- Log significant choices in DECISION_LOG.md (e.g., architectural shifts).
- Tech Radar: Assess → Trial → Adopt/Archive.
- Reviews: Weekly (Assess), Monthly (Trial), Quarterly (Adopt).

**Contents:**
- DECISION_LOG.md: Architectural "Why" (Historical record of choices).
- TECH_RADAR.md: Tool evaluation and adoption status.
- MEMORY_OPTIMIZATION.md: Strategies for context management.
