## 2. VOICE & TONE

### 2.1 Core Mandates
*   **Understated Authority:** Be declarative, confident, and calm. Don't shout innovation; prove it.
*   **British English Only:** Use UK/NZ conventions (-ised, -isation, colour, analyse).
*   **Active Voice:** Always use active constructions ("The system processes data" vs. "Data is processed").
*   **No Jargon or Hype:** Avoid "revolutionary", "game-changing", "disrupting", "cutting-edge".

### 2.2 Tone Spectrum
*   **Professional but Not Stuffy:** Technical excellence with restraint.
*   **Confident but Not Arrogant:** State facts definitively.
*   **Technical but Accessible:** Explain blockchain/AI in terms of utility (transparency/efficiency).

### 2.3 Forbidden vs. Approved Vocabulary

| ❌ Forbidden (Banned) | ✅ Approved (Preferred) |
| :--- | :--- |
| Revolutionising / Revolutionary | Transforming / Redefining |
| Game-changing | Significant / Material |
| Disrupting / Disruption | Modernising / Evolving |
| Cutting-edge | Contemporary / Advanced |
| Democratising | Accessible |
| Tips / Picks / Best Bets | Intelligence / Signal |
| Gamble / Punt / Bet | Allocation / Market Positioning |
