## 🆘 Troubleshooting

### "I can't find [X]"

1. Check this INDEX.md for location
2. Use grep to search all DNA: `grep -r "keyword" /home/evo/00_DNA`
3. Check if it's in INFORMATION_GAPS.md (not yet created)

### "DNA says [X] but I need to do [Y]"

1. DNA provides standards, not rigid rules
2. Document your exception and reasoning
3. If exception becomes pattern, update DNA
4. Never blindly follow—use judgment

### "DNA is outdated"

1. Update the relevant document
2. Mark old approach in graveyard/
3. Document why it changed
4. Update any dependent docs
